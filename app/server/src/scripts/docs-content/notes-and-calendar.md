One set of notes, two ways to look at them.

## Notes and Calendar are the same data

[Notes & Calendar](/notes) has two modes, and the switch between them changes the *view*, never the data.

- **Notes** — every note as a card, newest and pinned first.
- **Calendar** — a month grid, each note sitting on the day it belongs to.

There is no separate "calendar entry" type. A note appears in the calendar because of the day attached to it, and nothing else.

Anything written on the [Daily note](/docs/daily-notes) page is in here too, carrying a `daily` badge.

## Which day a note lands on

Every note shows up on exactly one day:

- If it has a **scheduled** day, it sits there.
- If it does not, it sits on the day it was written, and the day panel marks it `written` so you can tell the difference.

Set or clear the scheduled day with the date field on a note card. Clearing it sends the note back to the day it was written on.

:::callout{title="Scheduling is planning, not a deadline"}
A note also has an optional due date, kept separately. Scheduling says *when you intend to deal with it*; the due date says *when it has to be done*. Plan something for Monday that is due Friday and both stay true.
:::

## Right-click a note

Right-clicking a note — on a calendar chip or in the day panel — opens its menu:

- **Edit note…** — title, content and tags.
- **Pin / Unpin** — pinned notes sort to the top in Notes mode.
- **A colour** — six options including *No colour*. The current one is greyed out.
- **Unschedule** — only on a scheduled note; returns it to its written day.
- **Delete note** — asks for confirmation first.

Right-clicking an empty part of a day offers **New note on that day**.

:::callout{tone=warn title="Editing a note that has formatting"}
The edit dialog is plain text. If the note was written on the Daily note page with formatting, saving from here keeps the words and drops the formatting — the dialog warns you before it does. Edit rich notes on the [Daily note](/docs/daily-notes) page instead.
:::

## Colours

A colour is a label you choose, nothing more — it does not affect sorting, filtering or scheduling. Once set, it replaces the automatic accent a note gets from its type, and shows on the calendar chip and in the day panel.

## Finding things

In Notes mode:

- The **search** box matches title, content and tags at once, case-insensitively.
- **Tags act as categories.** Every tag in use appears as a chip; picking one narrows the list. Add tags to a note in its edit dialog, comma-separated.

Search and tags combine — a query plus a tag shows only notes matching both. Neither ever deletes anything; clearing them brings everything back.
