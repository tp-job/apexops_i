Welcome to Luminar

Luminar empowers you to create sophisticated voice AI agents that seamlessly integrate with your contact center operations.

Quick start

More tutorials

Our platform enables you to build voice agents that handle customer interactions with the same proficiency as your best service representatives.

Pre requirements

  • Active Voice AI Platform account
  • API key (get it from your dashboard settings)
  • Basic understanding of REST APIs
  • cURL, Python, or Node.js for examples

Before using voice processing features with your agent, you'll need to handle audio/video files in a specific way:

First, upload your audio or video file using our upload endpoint: POST /api/v1/media/upload

Content-Type: multipart/form-data
